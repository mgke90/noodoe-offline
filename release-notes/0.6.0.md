# Noodoe Offline 0.6.0

First stable release of the offline Android companion for KYMCO Noodoe /
Sunray dashboards.

## Highlights

- Pairing, SPP connection, device info, clock sync/custom clock, dashboard
  preferences, riding status, notifications, and background keepalive.
- **Dashboard Studio** clock and speedometer builders using the official
  SR1.5 Pack B assets, with a live 480×480 preview.
- Official in-flight transfer engine for large creations: up to ten active
  files, asynchronous start/finish handling, keepalive and commit.
- Native **64×90** stock speedometer digits.

## Install

1. Download `NoodoeOffline-0.6.0-release.apk`.
2. Install with `adb install -r NoodoeOffline-0.6.0-release.apk` or by opening
   the APK on the phone.
3. If you previously installed a **debug** build, uninstall it once. This
   release uses a different signing key.
4. Turn the scooter on, put the dashboard in pairing mode, open the app, grant
   Nearby devices + Location, and tap **SCAN & PAIR**.

## Requirements

- KYMCO Noodoe / Sunray dashboard. Compatibility varies by model, firmware,
  and resource pack.
- Android 6.0 or newer.
- The official Noodoe app must not be connected to the same dashboard.

## Known limitations

- Dashboard support varies by firmware and resource pack. Some units report
  key status incorrectly or use fixed unit faces.
- No firmware OTA, account, cloud, or social features.
- Do not use the app while riding.
