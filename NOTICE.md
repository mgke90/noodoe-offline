## Bundled dashboard assets

The APK and the `app/src/main/assets/creation_assets/` directory contain image
assets extracted from the official KYMCO Noodoe / Sunray SR1.5 resource pack
and official app presets. These assets remain the property of KYMCO, Noodoe,
or their licensors. They are **not** covered by the MIT License. They are
included solely so that the Dashboard Studio can generate clock and
speedometer creations that are compatible with the dashboard, and for personal
interoperability testing.

If you are a rights holder and want a particular asset removed, please open an
issue in this repository and it will be removed.

## Protocol information

The Bluetooth protocol implementation was developed by observing the official
app and the dashboard's behavior. No official application source code is
included in this repository. Unit tests use local fixture frames.
